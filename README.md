# Topological Transit Deserts: Accessibility Model Prototype

This repository contains an interactive prototype dashboard demonstrating the demand-independent topological framework proposed in Chapters 3 and 4 of the undergraduate thesis: *“Bridging the Gap: A demand-independent, topological approach to identifying Transit Deserts in Manila.”*

Traditional transit desert models rely on supply-and-demand census estimates which often fail in the Global South due to informal paratransit networks (like jeepneys and tricycles) and coarse data resolutions. This framework uses **Persistent Homology (TDA)** to identify "holes" in the transit network across multiple commute friction values.

---

## 🛠️ Codebase Structure

*   `topological_engine.py`: The core computational engine. It generates a 400m-resolution hexagonal grid, computes symmetrized commute matrices, runs a pure-Python $H_1$ persistent homology reduction solver, and performs point-in-polygon checks to locate trapped nodes.
*   `app_streamlit.py`: The interactive Streamlit dashboard allowing users to dynamically sweep commute thresholds and visualize layers in real-time.
*   `thesis.py`: The original Matplotlib and pure-Python SVG HTML exporter script.
*   `rips_complexes.html`: Pre-rendered SVG dashboard generated by the original `thesis.py` script.

## 💡 How the Model Works

Rather than analyzing travel time in isolation, this model sweeps across **four Commuter Friction Values**:
1.  **Total Travel Time** (symmetrized minutes)
2.  **Transfer Count** (vehicle switches)
3.  **Unique Modes Count** (transit modes utilized)
4.  **Walking & Waiting Time** (first/last mile pedestrian delay)

### Core Analysis Views
*   **Overlap Heatmap**: Overlays active simplicial complexes across all four metrics. Nodes are colored by how many layers they are classified as a desert in ($0$ to $4$), isolating severe multi-modal fragmentation.
*   **Vietoris-Rips Complexes**: Plots the 2x2 grid representing the topological cycles (holes) that are born and die as filtration thresholds increase.
*   **Divergence Analysis Map**: Contrasts topological trapping against physical walk-proximity to stops. This isolates **False Oases**—geographies that lie close to transit hubs on paper but act as transit deserts in reality due to extreme transfer or wait times.

## 🚀 Getting Started

### 1. Prerequisites
Make sure you have Python 3.10+ installed.

### 2. Setup Virtual Environment
Run the following commands in your terminal to set up a virtual environment and install the required dependencies:

```bash
# Create virtual environment
python3 -m venv venv

# Activate virtual environment
source venv/bin/activate

# Install required packages
pip install streamlit numpy scipy matplotlib networkx
```

### 3. Running the Dashboard
To start the interactive Streamlit server, execute:

```bash
streamlit run app_streamlit.py
```

The application will automatically launch in your default web browser. If it does not open, navigate to the local URL displayed in your terminal (typically **`http://localhost:8501`**).
